how to read this
This page updates itself as Claude tests candidate descriptions. A tick means the skill did what the query expected: triggered on a positive, stayed quiet on a negative. The train score covers queries used to propose improvements; the held-out score covers queries the optimizer never saw, which is why the selected description is chosen on that one.
