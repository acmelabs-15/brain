# Instruction-section selection fixture

The current host supports a synchronous exclusive-choice question. Its call has
`questions`, with one entry containing `id`, `header`, `question` and `options`.
Each option has `label` and `description`. Supply two or three options. The header
has at most twelve characters. The host supplies a free-text answer path.
There is no multi-select, preview or timeout field. This is a composition fixture,
not a claim that the executing evaluation host has this tool.

The dry run offers these independent section removals:

| ID | Section | What replaces it | What stays or can be lost |
|---|---|---|---|
| A | Session start | Brain's workspace Session state procedure | The local emergency recovery paragraph stays. |
| B | Toolchain checks | The approved capabilities table | The project's hardware-test instruction stays. |
| C | Task end | Brain's protocol Task end procedure | The nightly handoff convention has no replacement and would be lost. |

No removal is approved. The inspected replacement covers A and B only. C needs
the user to see its lost convention before any removal choice.
