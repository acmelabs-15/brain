## Design intent — required
Establishes the architectural decision rejecting a separate verify skill or dedicated `--verify` flag for `setup-matt-pocock-skills`. Because the skill is prompt-driven, verification is achieved conversationally by instructing the setup skill to check existing files against seed templates without rewriting them. This avoids code duplication, fragmented surface area, and synchronization drift between setup and verification logic.
