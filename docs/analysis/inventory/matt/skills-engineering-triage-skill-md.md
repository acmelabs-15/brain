## Design intent — required
The primary intake and routing engine in matt's engineering skill suite for externally originated issues and pull requests. Operates a state machine assigning each item exactly one category role (`bug`, `enhancement`) and one state role (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Treats PRs as issues with attached code. Enforces empirical claim verification (reproducing bugs, running test suites against PR diffs), detects redundant existing implementations, checks against the `.out-of-scope/` knowledge base, conducts multi-round grilling via `grilling` and `domain-modeling`, and outputs durable agent briefs or structured triage notes. Configured with `disable-model-invocation: true` to require explicit invocation.
