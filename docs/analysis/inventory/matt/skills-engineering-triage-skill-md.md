## Design intent — required
Operates an issue and external pull request triage workflow governed by a strict two-dimensional state machine: exactly one category role (`bug` or `enhancement`) and one state role (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, or `wontfix`). Treats PRs uniformly as issues with attached code. Enforces disciplined verification—reproducing bug reports and testing PR diffs—before recommending states or writing briefs. Integrates `grilling` and `domain-modeling` when requests require clarification, checks against prior rejections via `.out-of-scope/`, and publishes durable agent briefs or structured triage notes.
