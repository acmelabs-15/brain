## Design intent — required
Provides an automated architectural linting configuration for `dependency-cruiser` to enforce deep module encapsulation across a TypeScript repository. Restricts consumers (both outside application code and neighboring packages) to importing only through a package's root entry points while hiding all subfolder internals (`lib/`, etc.). Ensures unit and integration tests exercise packages through these public entry points rather than reaching into private implementations, preventing encapsulation leaks and circular dependencies.
