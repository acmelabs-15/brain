## Design intent — required
Implements the core runtime execution engine, helper library, and UI components for interactive bash setup scripts generated by the `/wizard` skill. Delivers a clean terminal interface with dynamic color formatting, stage progress counters, screen-clearing step isolations, cross-platform browser URL dispatch (supporting WSL `wslview`, Windows `explorer.exe`, Linux `xdg-open`, and macOS `open`), masked secret input, idempotent `.env` file upserts, and GitHub Actions repository secret/variable configuration via the `gh` CLI. Serves as both the boilerplate library and a runnable template with a built-in Stripe onboarding stage.
