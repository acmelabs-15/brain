## Design intent — required
Automates security verification for exported memory JSON files (such as those generated by Forgetful or memory export workflows) by scanning line by line against regex patterns for API keys, tokens, passwords, secrets, private file paths, database connection strings, email addresses, and PII patterns before files are committed to version control. Without it, developer credentials, private system paths, and personal data could leak into git repositories via memory export bundles.
