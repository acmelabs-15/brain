## Design intent — required
Provides pure, side-effect-free statistical comparison logic to evaluate whether candidate models outperform a harness default model sufficiently to justify keeping an explicit model pin in agent or skill configurations. Implements paired bootstrap 95% confidence intervals with Bonferroni family-wise alpha adjustment across candidates on shared stable fixtures. Enforces rigorous verdict semantics (`KEEP_PIN` vs. `DROP_PIN`) and builds standardized machine-readable sweep artifacts. Without this module, decisions to pin specific models would lack empirical and statistical justification, risking pinned sub-optimal models and unverified performance claims.
