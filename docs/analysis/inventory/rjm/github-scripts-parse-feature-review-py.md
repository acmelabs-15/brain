## Design intent — required
Extracts structured triage metadata (recommendation, assignees, and labels) from raw AI review output evaluating new feature requests. It acts as an integration glue script between AI review steps and GitHub Actions workflows, saving raw responses to `/tmp/feature-review-output.txt` for auditability and writing parsed triage outputs to `$GITHUB_OUTPUT` using helpers from `scripts.ai_review_common`. Without this script, feature review recommendations generated by AI would require fragile inline bash regex parsing in workflow YAML files to extract reviewers and labels.
