## Purpose — required, verbatim
> "Exec-path vendor-portability ratchet baseline for skill Markdown files (issues #2838, #4013, #4156). files counts bare '.claude/skills/...', 'build/...', or 'scripts/...' executable invocations per file. marker_files records invocations suppressed by '<!-- vendor-portability-exec: ... -->' markers. ## Design intent — required
Provides an explicit, version-controlled baseline ratchet for bare executable invocations (`.claude/skills/...`, `build/...`, `scripts/...`) found across skill Markdown instruction files (`SKILL.md`, `references/**/*.md`, `scripts/README-*.md`) across both the canonical Claude tree (`.claude/skills/`) and the generated Copilot CLI tree (`src/copilot-cli/skills/`). In a vendored plugin installation, skills live at the plugin root rather than `./.claude`, so hardcoded bare paths break execution. By tracking per-file violation counts (`files`) and marker-suppressed counts (`marker_files`) enforced by `check_skill_md_exec_portability.py`, this baseline prevents regression while allowing incremental migration to portable environment-variable fallbacks (`${COPILOT_PLUGIN_ROOT:-${CLAUDE_PLUGIN_ROOT:-.claude}}`). Without this ratchet, PR validation would either break completely on pre-existing legacy documentation debt or fail to catch newly introduced unportable execution commands.
