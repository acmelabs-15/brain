## Design intent — required
Provides a complete, standardized markdown template and reference exemplar for threat models generated by autonomous agents or developers. It supplies the required document hierarchy and markdown table schemas expected by `validate_threat_model.py`: Scope (Subject, Boundaries, Stakeholders), Architecture Overview (ASCII DFD, Component table, Data Flow table, Trust Boundaries, Assets), STRIDE Analysis sections detailing threats T001–T011 across all six categories, a Threat Matrix Summary, prioritized Mitigations with designated owners and target milestones, Accepted Risks with justifications, and a Validation Checklist. As a template populated with realistic illustrative threats, it acts both as authoring scaffolding and as an executable test fixture for model validation tooling.
