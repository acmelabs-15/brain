> "Detailed prompt templates for each phase of ADR review." — .claude/skills/adr-review/references/agent-prompts.md:6

## Design intent — required
Standardizes subagent prompt construction across all four phases of multi-agent ADR review (Phase 1: Independent Review, Phase 2: Consolidation, Phase 3: Resolution, Phase 4: Convergence Check), plus scope-split recommendations. It defines the specialized review lens, checklists, and output schemas for each participating agent (architect, critic, independent-thinker, security, analyst, and high-level-advisor). Without it, orchestrating agents would lack uniform instructions for structural compliance, adversarial critique, threat modeling, empirical validation, conflict resolution rulings, and convergence voting (Accept, Disagree-and-Commit, Block).
