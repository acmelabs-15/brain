## Design intent — required
Parser module for extracting structured decision data from unstructured or semi-structured feature review AI output (such as generated by the `issue-feature-review` agent). Extracts triage recommendations (`PROCEED`, `DEFER`, `REQUEST_EVIDENCE`, `NEEDS_RESEARCH`, `DECLINE`), suggested assignees (cleaning GitHub usernames and discarding "none suggested" filler), and suggested issue labels (parsing backtick-wrapped and plain label identifiers). Provides conservative keyword fallback rules (DECLINE > DEFER > PROCEED) to prevent false positives when explicit headers are absent. Without this file, automated GitHub issue triage workflows would be unable to reliably convert agent review responses into automated label assignments, assignee routing, and issue milestone actions.
