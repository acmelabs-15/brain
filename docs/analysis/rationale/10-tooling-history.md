# 10 · The tooling — why each script exists, and the bugs found on the way

Every script under `scripts/synthesis/` is pure Bun (R9), takes paths and prints text, and knows nothing about brain's layout. This is the record of why each one exists and what it fixed. The scripts' own header comments are the reference for their flags; METHOD §9 lists them.

## The principle behind all of them

A fact a script can compute is never typed by the model (R11, M5). A check a script can run is never asserted in prose (R2). Two consequences shaped the set: everything the primary agent needs to *know* about a unit is printed by a script (`unit-facts.ts`), and everything a card *claims* is checked by a script (`quote-check.ts`, `coverage.ts`, `memo.ts`).

## The bugs, in the order they were found

1. **Phantom check-offs (session 012).** `existsSync` on macOS is case-insensitive; 127 markdown files spelt `SkillForge` for the directory `skillforge`; the same file entered the manifest twice and cards ticked rows they did not belong to. Fix: `realpathSync` in the walker; card presence decided by exact string match against a directory listing; slug collisions abort the run.
2. **rjm agents unreachable (D-013).** `Task(subagent_type="x")` → `.claude/skills/x/` only. Nine agent definitions and their divergence from `templates/agents/*.shared.md` (23–380 lines each) were invisible. Fix: resolve to `.claude/agents/x.md` *and* `.claude/skills/x/`.
3. **No citation ever checked.** `quote-check.ts` written 2026-09-04; 18% of the existing citations failed.
4. **STATE `done` rows pointing at non-existent reports (session 013)** — a kit bug in the experiment-mode re-partition; the agent's §8.1 step 6 caught it and marked them pending, which is what step 6 is for. `units.ts mark done` now refuses such a row.
5. **Fabricated URLs** in the agent's first experiment doc; replaced. Rule: every harness claim cited or marked `undocumented — probe`.
6. **Teamwork scratch committed under `.agents/`** (sessions 013–014) — the Part-2 plugin mirror directory. `.gitignore` now ignores `.agents/*` except the four mirror paths.
7. **The statusline log deleted** by the kit that replaced the statusline directory (run-01 series lost). `apply-final.sh` appends an old log before replacing.
8. **`per_unit_delta = 0.53`** — the run's fixed cost divided by its unit count; true per-unit cost 0.19 (transcript attribution, 2026-09-04 capture).
9. **Matt's external pages absent** (37 rows) and **matt's skills lumped by category** (56-file unit) — both from the `skills/<name>/` assumption; found on 2026-09-05 while re-running Phase 0 on a clone.
10. **Binary files as inventory rows** — 13.5 MB of PNGs under `skillforge/assets/` were rows expecting cards; now type `asset`, no card, listed to the Worker.
11. **METHOD read twice.** The file viewer stops near 46 KB; METHOD (68 KB) was read as 1–410 then 400–532, costing 1.6% per conversation. Now two exact views, 1–320 and 321–end (the split moved from 300 with D-021, which grew the manual to 78 KB), both under the limit.
12. **Headless conversation read the wrong worktree** (session 001). Given `Read docs/plan/METHOD.md` with no stated root, the headless agent searched `/Users/peterkloss` by file name and read `…/ACMElabs/brain/docs/plan/{METHOD,STATE,DECISIONS,…}.md` — the discarded first attempt, fenced by DO-NOT-READ — before locating `brain-v2`. Interactive Phase 0 had not done this. Fix: PROMPT.md and METHOD §8.1 state the absolute root and forbid filesystem searches for named files; the outputs of that session were script-verified and stand.
13. **`drive.ts` parsed the wrong shape** (session 001). Events are `{event, <event>: {…}}`, not flat; `usage.input_tokens` is the *uncached* prompt and the context is `input_tokens + cache_read_tokens`; the statusline renders headless so the driver's own log is a fallback, not the source. Replaying the saved stream through the fixed driver reproduces the statusline's peak within 0.1%.
14. **Whole-METHOD memo key** (sessions 002–003). A between-session edit to the *operational* sections of METHOD.md (hotfix 1) changed the file hash every card recorded; `memo.ts audit` reported 90 STALE and the agent stopped, correctly, under §10. The agent's handoff diagnosed it and posed the choice; D-020: the key is the extraction contract (§2.4, §3, §4) plus the template, `memo.ts restamp --all` re-hashes without touching model, effort or `verified:`, and the 90 cards were re-stamped, not re-run.
15. **Kit-script portability**, for the record: macOS ships bash 3.2 (`declare -A` fails — use `case` functions); zsh treats a `#` inside a pasted command block as an argument (never put comments in a paste block); agy's `statusLine`/`title` settings must be objects with absolute paths; a `while read` loop whose last iteration returns non-zero kills a `set -e` script silently (the first `capture-experiment.sh` produced no zip for that reason).
16. **The `run-start` label carried a guessed count** (test series). `budget.ts --record "run-start … n=16"` was recorded when the verdict said 12, then corrected; and `n=2`, `n=1` were recorded against a STOP. The label is evidence, so the script now refuses a count that is not the plan's `n` (D-021).
17. **The wall-time bound measured the Orchestrator** (test series). Runs with 2–3 units per Worker or sequential gated milestones took 23–65 minutes at the same caps; the rule read that as the harness queueing. Fix: the brief requires one Worker per unit at once, and the test applies only between runs of that shape (D-021).
18. **Two harness quirks, one wasted step each per conversation** (test series, every stream): the first sandboxed `run_command` fails with `sandbox configuration error: deny ~/.ssh/**: globs not supported` (from the `read_file(~/.ssh/**)` deny rule in `settings.json`); `write_to_file` into the repository is refused in headless mode (`artifacts must be in …/antigravity-cli/brain/<conversation>/`). Both are said in `PROMPT.md`; neither is fixed by the project (the first is Peter's settings file).
19. **agy's ERROR after a finished conversation** (session 004): `"The stream was interrupted. Please continue the task you were working on."` after the final paragraph, everything committed. The driver counted it as a failure; now it is FINISHED (yellow) when the handoff is complete and the tree clean (D-021).
20. **Ctrl-C on the driver did not stop the conversation** (test series, 2026-09-04/05). `drive.ts` spawned agy as a child; the interrupt killed the driver and left agy running for nine hours, in which it verified and committed a run and half-stamped another. Fix (D-021): the driver traps SIGINT/SIGTERM, kills its agy child, records the interruption, and exits; the STOP file remains the graceful way to stop.
21. **`_verification.md` counted as a card** (production series, session 010). METHOD §5 places the Phase 1V report at `docs/analysis/inventory/<pkg>/_verification.md`; `coverage.ts`, `memo.ts` and `quote-check.ts` listed every `.md` there as a card except under `_units/` and `_divergence/`, so three orphan, unstamped "cards" appeared and the agent stopped for Peter — correctly. Fix (D-022): `isCardPath` in `_lib.ts` — no `_`-prefixed file or directory is a card — used by all three.
22. **Waiting cost context** (production series, sessions 005 and 007). `await-run.ts` returned every `--wait` seconds (240) or on a 15-minute stall; through 4–7-hour quota pauses that was hundreds of returns, each a model call that failed and retried during the quota window, plus a reply to every Sentinel progress message: +9.75 % and +8.48 % of the window while nothing happened, a peak of 24.4 % and one compaction. Fix (D-022): a stalled run keeps the call blocking (up to `--stall-max 180` minutes); the brief asks the Sentinel for completion/blocked messages only.
23. **A re-run would have been skipped by the memo** (found while writing the 1V procedure). §7 step 1 reuses any unit whose deliverables HIT; a unit re-run after 1V has unchanged inputs, so its stale cards would HIT. `units.ts rerun` removes the deliverables first (D-022).
24. **Phase 2 had no unit system** (production series, session 013). `units.ts`, `budget.ts` and `unit-facts.ts` knew only `manifest/units.md`; §5's "one subagent per package" met 11,259 concepts in rjm. Fix (D-023): `partition-concepts.ts` → `manifest/units-p2.md`; `readUnits()` reads both manifests so every consumer sees one unit set; `unit-facts.ts` and `memo.ts` branch on `cc-` units; the loop is unchanged.
25. **Per-card stamping and `verified:` edits would not scale to 13,765 cards** (found while writing D-023). Phase 1's §7 steps 5–6 cost the primary one stamp line and one edit per card — fine at four cards per unit, impossible at thirty. Fix: `memo.ts stamp-unit <unit>` and `memo.ts verify <unit>`, one call and one line each; `verify` runs quote-check itself and refuses to write on any FAIL.
26. **A concept without a card was about to be a coverage failure** — which would have stopped every Phase 2 conversation at §8.1 step 8 until the phase was finished. Fix: counted as pending work, like an uncovered manifest row in Phase 1; Phase 2's *Done when* is zero.

## What was deliberately not built

- A separate reviewer role for `verified:` — the primary agent writes it at §7 step 6, after the scripts pass; a role would add a message without adding a check.
- A `teamwork_preview`-specific client — the dispatch is the documented `invoke_subagent`; the run is read from files.
- Any script that summarises a source, ranks cards by importance, or samples files. R1 (full reads) is enforced by the manifest, not by tooling that decides what to skip.
