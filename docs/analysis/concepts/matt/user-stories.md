## Design notes
User stories form a core section of Matt's specification template generated by `to-spec`. Required to follow the canonical `As an <actor>, I want <feature>, so that <benefit>` structure, they ground feature requirements in concrete user motivations and outcomes. While highly effective for user-facing applications, Matt's documentation notes that user stories are less suited for purely architectural changes or internal refactorings, where implementation and testing decisions provide a better structural lens.
