## Design notes
An AFK runner is an autonomous background process that polls an issue tracker for tasks carrying `ready-for-agent` and executes them without continuous human interaction. The entire specification pipeline (`to-spec` → `to-tickets` and `/triage`) is designed to supply these runners with durable, unambiguous briefs so they never block on missing decisions.
