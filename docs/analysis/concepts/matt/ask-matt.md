User situation descriptions, stuck points, and problem contexts.

## Produces
Recommended next skill or sequence of skills to execute, highlighting where human decisions sit.

## When applied

## Design notes
The global entry router for matt's skill catalog. It listens to a developer's current situation, maps it to the appropriate skill or multi-skill chain, and halts without taking autonomous action so the user remains in control of what executes next.
