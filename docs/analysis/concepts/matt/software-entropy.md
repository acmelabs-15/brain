## Design notes
Software entropy represents the natural degradation of structural clarity and increase in complexity as software evolves. Because AI agents generate code at high velocity without inherent awareness of global architecture, they dramatically accelerate entropy, turning systems into unmaintainable balls of mud unless countered by deliberate design disciplines like deep modules.
