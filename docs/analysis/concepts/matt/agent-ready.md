## Design notes
`agent-ready` describes the intrinsic quality of tickets produced by `to-tickets`. Because `to-tickets` rigorously sizes tickets to single context windows, enforces vertical tracer-bullet slicing, defines test seams, and links blocking dependencies, the resulting work items require no additional triage or refinement before an autonomous agent can begin implementation.
