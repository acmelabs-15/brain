## Consumes
Per-repo configuration generated by `/setup-matt-pocock-skills` (issue tracker targets, triage label strings).

## Produces
Accurate issues, tickets, and triage labels published directly to external issue systems.

## When applied

## Design notes
Classification for skills whose output is fundamentally incorrect rather than merely vague when repository configuration is absent. Skills in this category (`to-tickets`, `to-spec`, `triage`) must include an explicit one-liner directing the user to run `/setup-matt-pocock-skills`, ensuring agents do not hallucinate tracker destinations or label taxonomies.
