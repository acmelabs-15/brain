## Design notes
Red Flags provide concrete, observable symptoms that indicate an agent is deviating from a skill's intended process. By enumerating specific anti-patterns (such as deleting tests to achieve a green build, guessing at bug causes without reproduction, or committing without verification), Red Flags enable early detection of process failures before defective code is merged.
