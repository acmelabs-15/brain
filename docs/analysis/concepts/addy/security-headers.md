## Design notes
Security headers are HTTP response headers that instruct client browsers to enforce strict defensive boundaries against clickjacking, MIME sniffing, protocol downgrades, and script execution. Addy provides a baseline configuration comprising CSP, HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, and Permissions-Policy to harden the application against client-side exploitation.
