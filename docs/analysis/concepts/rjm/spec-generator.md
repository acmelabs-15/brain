## Design notes
Transforms informal or vague feature descriptions into formal, testable 3-tier engineering specifications (Requirements in EARS syntax, Design documents, and atomic Task breakdowns). In rjm's architectural evolution, spec-generator was transitioned from an autonomous agent to a skill bundling a deterministic Python schema validator (validate_spec_frontmatter.py) to prevent LLM frontmatter enum hallucinations from entering repository specifications.
