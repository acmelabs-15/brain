## Design notes
DRIFT DETECTED is an automated quality gate classification in rjm's multi-platform agent synchronization workflow. Because Claude Code agent prompts are maintained in a separate tree from generated Copilot/VS Code templates, DRIFT DETECTED serves as the sentinel verdict that halts unattended divergence, compelling developers to reconcile prompt changes across platforms or document intentional variances.
