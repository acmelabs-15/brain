## Design notes
REQ-003-010 establishes an uncompromisable boundary invariant in rjm: generators must never write into the canonical `.claude/` tree. Because `.claude/` is the authoritative source for skills, rules, and configurations, allowing automated generators to write to it risks circular overwrites, corruption of source definitions, and erosion of the canonical boundary.
