## Design notes
Size Labels standardizes bracketed task metadata prefixes (`[XS]` through `[XXL]`) in issue titles. These labels provide a deterministic signal for the orchestrator to automatically select model capability tiers (routing simpler tasks to faster, lower-cost models and complex tasks to high-capability models) and flag multi-component work requiring further decomposition.
