## Design notes
FM #11 ("Customer-facing generated artifact shipped without runtime verification") is an established governance failure mode in rjm. It codifies the organizational learning from incident #2205 (where unanchored plugin hooks wedged client environments for 33 days) and mandates that all generated artifacts must be executed and verified in realistic target environments with negative controls.
