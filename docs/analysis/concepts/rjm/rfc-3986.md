## Design notes
RFC 3986 (Uniform Resource Identifier: Generic Syntax) serves as the authoritative standard for URI parsing in rjm's link validation gates. In `check_adr_links.py`, its scheme ABNF and network-path reference rules are implemented to accurately identify external URLs and network destinations, preventing false-positive broken link reports on external resources that match ADR naming patterns.
