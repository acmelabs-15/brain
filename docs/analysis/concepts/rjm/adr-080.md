## Design notes
ADR-080 establishes the model pin justification policy across the repository, treating model version pinning as technical debt governed by a draining ratchet. Under ADR-080, skills and commands are prohibited from specifying versioned model IDs, defaulting instead to the harness-inherited model; the only permitted exception is a bare rolling alias (such as haiku) that prices strictly below the default and carries an explicit cost-justification rationale.
