## Design notes
CWE-798 (Use of Hard-coded Credentials) represents the exposure of embedded authentication tokens, passwords, or keys in source files. In rjm, hard-coded credentials immediately trigger a BLOCKED verdict and disqualify code changes from quick-pass clearance.
