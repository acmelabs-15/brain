## Design notes
The foundational strategic logic of Blue Ocean Strategy in rjm. It rejects the conventional economic assumption that higher buyer value requires higher costs, demanding that strategic moves simultaneously drive costs down (via elimination and reduction) and buyer value up (via raising and creation).
