## Design notes
The Multi-agent verification pattern shifts the burden of correctness from rigid single-turn prompt constraints to multi-agent systemic oversight. By deploying peer agents whose explicit mandate is to challenge assumptions and identify fabrications, systems achieve robust verification without burdening individual prompts with unenforceable legalistic instructions.
