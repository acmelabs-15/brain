New: the `brain` CLI, which skills and sessions run with bun. `brain new-doc` creates the next numbered file (IDEA, DEC, RES or SPEC), `brain check` checks the workspace against its rules, `brain status` reports the stage, the last step and the next step, and `brain plan` prints what can run at once in a spec's plan. The `status` skill gives the same report from inside a session.
